Simmuse Agent

A personal AI agent that works from your terminal, a desktop app and your chat apps. It remembers across sessions, runs scheduled jobs and delegates to subagents.

Download the pre-release Read the docs Source on GitHub

macOS

DMG for Apple silicon and Intel Macs.

Linux

AppImage for x64.

Command line

One-line install on Linux, macOS and Windows.

curl -fsSL https://raw.githubusercontent.com/ssajvinder-alt/Simmuse-Agent/main/scripts/install.sh | HERMES_REPO_URL=https://github.com/ssajvinder-alt/Simmuse-Agent.git bash
Pre-release builds are unsigned, so macOS and Windows will warn on first launch. How to open them.
